# A Guard Nothing Runs

## Failure
A family of allowlist ratchets was correct, and every one lived in a test tier that CI never executed. Two allowlists drifted for weeks while the discipline read as enforced. One drift had already been diagnosed and fixed on a branch that never became a PR, so it was rediscovered from scratch.

## Root mechanism
A guard's authority came from its existence in the repository, not from a gate that ran it. Nothing went red because nothing ran.

## Rule paid for
A guard is only as real as its execution path. Name the gate that runs it, or call it documentation.
