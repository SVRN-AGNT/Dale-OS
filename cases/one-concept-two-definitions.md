# One Concept, Two Definitions

## Failure
Two parts of a system used different predicates for the same word. Each implementation was internally consistent and the system contradicted itself at the seam.

## Root mechanism
Duplicated authority.

## Rule paid for
Find the canonical definition, route all consumers through it, and pin the seam.
