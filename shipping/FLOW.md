# Before and after, stage by stage

Each row follows one stage a change passes through in the reference repository, from an agent writing it to production. **Kind** names the change: cut fat, improved, redundancy removed, or hole filled. **State** is as of 14 October 2026, checked on GitHub. Numbers are the threads' own measurements unless marked *expected*.

The owner also has an interactive version of this table as a private page, kept outside this repository.

The table shows the state on 14 October 2026. Several rows marked built or pending have since landed: terse test output, the skip for already-tested trees, the red-run alert, promotion receipts and the truth gate all merged that day, and held scope has landed through the merge gate since 16 October ([`README.md`](README.md#status-on-14-october-2026)). Rows waiting on the owner are not updated here.

## The trade-off

Held-scope PRs merged by hand that day carry no Controller attestation. That forces the next release into full consolidation mode, the slow path with every checklist item and the whole suite. Since 16 October held scope goes through the Controller via the merge gate instead; agents' own identity is still what would close the forged-evidence gap in the gate's threat model.
